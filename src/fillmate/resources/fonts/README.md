Fonts used by the "Ink and hand" look (`src/fillmate/gui/ink.py` loads every `.ttf` here):

- **Inter** (interface text), from https://github.com/google/fonts/tree/main/ofl/inter
- **Caveat** (fillmate's red-pen notes), from https://github.com/google/fonts/tree/main/ofl/caveat
- **Courier Prime** (paths and code), from https://github.com/google/fonts/tree/main/ofl/courierprime
- **Archivo** (the big pack name behind the main window, at its expanded width), from
  https://github.com/google/fonts/tree/main/ofl/archivo

All four are under the SIL Open Font License 1.1; see the `OFL-*.txt` files.
